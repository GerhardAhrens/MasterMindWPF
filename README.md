Das Master Mind Spiel wurde auf .NET 10 migriert und ist jetzt mit Visual Studio 2026 kompatibel. Es bietet eine moderne Benutzeroberfläche und verbesserte Leistung. Das Spiel ist unter der MIT-Lizenz verfügbar, was bedeutet, dass es frei verwendet, modifiziert und verteilt werden kann.

# Zum Projekt
Das Projekt dient mir als Fingerübung, um die neuen Funktionen und Verbesserungen von .NET 10 zu erkunden. Es ist eine großartige Gelegenheit, meine Fähigkeiten in der Entwicklung von WPF-Anwendungen zu verbessern und gleichzeitig ein unterhaltsames Spiel zu erstellen.

Der Fokus bei diesem Projekt liegt auf der Erstellung von Controls `EllipseButton` und der Erstellung von Texturen für einen Hintergrund für ein `UserControl`. Es ist eine spannende Herausforderung, die es mir ermöglicht, meine Kreativität und mein technisches Wissen weiter zu verbessern.

# Spielbrett

Das Spielbrett besteht aus einem Raster von 4x10 Zellen, in dem ein Spieler seine Farbcode-Kombinationen platzieren kann. Jede Zelle kann eine von sechs Farben enthalten, und die Spieler müssen versuchen, die geheime Farbcode-Kombination zu erraten, die vom Computer generiert wird.
